== XTEC Eduhack ==

Theme and settings of the blogs of the EduHack projects (2017). The blogs are no longer created: the form to create
them and the copy of the template have been removed, and the plugin keeps what the existing blogs use.

- The theme eduhack, a child theme of Fukasawa, which is in the folder themes of the plugin.
- The image and the color of the categories, which the theme shows with the posts.
- The classes of the widgets of each phase, which were chosen with the plugin Widget Options.
- The template of the projects (site option eduhack_template_id) is only available to its members and super admins.
- The administrators of the blogs can't change the theme nor the categories.
